BoogdiBot 개인정보처리방침

시행일: 2026년 10월 15일

1. 앱 소개

BoogdiBot은 개발자 본인만 사용하는 개인용 일정 비서이며, 일반 사용자에게 제공되지 않습니다.

2. 접근하는 데이터

  • Gmail: 메일 읽기, 처리한 메일에 라벨 추가
  • Google Calendar: 일정 생성·수정·삭제

3. 사용 목적

메일 내용에서 일정 정보(날짜, 시각, 장소, 예약번호 등)를 추출해 사용자 본인의 캘린더에 등록하고, 등록 결과를 사용자 본인의 텔레그램으로 알리는 데만 사용합니다.

4. 외부 전송

일정 정보 추출을 위해 메일 본문이 Anthropic Claude API로 전송됩니다. 데이터는 광고, 판매, 모델 학습 등 다른 목적으로 사용하거나 제3자에게 제공하지 않습니다.

5. 저장

Google 인증 토큰은 사용자 본인의 컴퓨터나 서버에만 저장됩니다. 메일 내용은 따로 저장하지 않습니다.

6. 권한 해제

Google 계정 → 보안 → 타사 앱 및 서비스에서 언제든 BoogdiBot의 접근 권한을 해제할 수 있습니다.

7. Google API 서비스 정책 준수

BoogdiBot이 Google API로 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

8. 문의

English summary: BoogdiBot is a personal app used only by its developer. It reads the developer's Gmail and manages events in the developer's Google Calendar. Email content is sent to the Anthropic Claude API solely to extract event details; it is not sold, shared, or used for advertising or training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
